# פותר המשחקים של LinkedIn

עוזר למשחקי LinkedIn. פתרון אוטומטי של חידות יומיות (Queens, Sudoku, Pinpoint, Crossclimb) עם רצפים וניתוח נתונים.

## למה להתקין?

- לעולם אל תאבדו רצף: שמרו על המומנטום היומי שלכם והבטיחו שהרצף לא יישבר, גם בימים הקשים ביותר או כשאתם קצרים בזמן.
- שלוטו בחידונים ובחידות מילים: משחקים כמו Crossclimb ו‑Pinpoint דורשים ידע טריוויה עמוק וקישור מהיר. ה‑AI המובנה פותר אותם בדיוק גבוה.
- רישום תשובות היברידי: פתרו את Crossclimb ו‑Pinpoint מיידית ללא כל עלות API באמצעות מאגר התשובות המרוחק שלנו, ללא צורך במפתחות AI אישיים.
- תמיכה מלאה במשחקי בונוס: פתרו בצורה חלקה גם חידות יומיות סטנדרטיות וגם שלבי בונוס מקומיים (Queens, סודוקו וכו׳) עם מעקב רצף נפרד וסמל "Bonus" ייעודי בלוח הבקרה.
- אינטגרציה מקורית לחלוטין: שכבת הפותר מופיעה ישירות בלשונית המשחק הפעילה שלכם. בלחיצה אחת תראו את הלוח הפתור ישירות על המסך.
- מצב רמז חינוכי: למדו לפתור חידות בצורה טבעית. במקום השלמה אוטומטית, קבלו הצעה למסע לוגי אחד, וגילו טעויות מיידית באמצעות סימון אדום על המסך.
- מהירות פתרון סמויה (מצב Stealth): הדמו התנהגות קליקים אנושית עם עיכובים אקראיים וטבעיים (1–3 שניות) כדי להגן על רצף הפתרון היומי שלכם מפני מנגנוני זיהוי בוטים.
- קיצורי דרך מודעי-הקשר: השתמשו באפשרויות תפריט ההקשר בלחיצה ימנית כמו "סמן כלא שוחק", "פתור" או "קבל רמז" ישירות מכרטיסי המשחק.
- בינה מלאכותית מובנית מקומית של Chrome: חברו את מודל Gemini Nano המובנה ב‑Google Chrome לחוויית פתרון חידות מקומית לחלוטין, פרטית וללא עלות.
- לוח בקרה אנליטי יפה: עקבו אחר היסטוריית הפתרון, זמני הממוצע, הרצפים והשיאים האישיים שלכם באמצעות לוח מחוונים מודרני ומתקדם המבוסס על לוח שנה.
- פרטי ומאובטח: פועל כולו בתוך הדפדפן שלכם. מפתחות ה‑API שלכם מוצפנים מקומית באמצעות AES-256 ואינם משותפים לעולם עם שום שרת. ניתן בכל עת להצטרף או לבטל השתתפות בטלמטריה אנונימית.
