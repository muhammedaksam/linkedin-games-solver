# LinkedIn 게임 솔버

LinkedIn 게임을 위한 도우미입니다. 일일 퍼즐(Queens, 스도쿠, Pinpoint, Crossclimb)을 자동으로 해결하고 연속 기록과 분석을 제공합니다.

## 왜 설치해야 하나요?
* 연승을 절대 놓치지 마세요: 가장 힘든 날이거나 시간이 부족할 때에도 매일의 흐름을 이어 가며 연속 기록을 안전하게 지키세요.
* 상식 퀴즈와 단어 퍼즐을 마스터하세요: Crossclimb과 Pinpoint 같은 게임은 깊은 상식과 빠른 연상이 필요합니다. 내장된 AI가 높은 정확도로 이를 해결합니다.
* 하이브리드 답변 레지스트리: 원격 정답 데이터베이스를 사용해 개인 AI 키 없이도 API 비용 0으로 Crossclimb과 Pinpoint를 즉시 해결하세요.
* 보너스 게임 완전 지원: 표준 데일리 퍼즐과 현지화된 보너스 레벨(Queens, Sudoku 등)을 모두 자연스럽게 해결하고, 독립적인 연속 기록 추적과 전용 대시보드의 "Bonus" 배지도 제공합니다.
* 완전한 네이티브 통합: 해결 오버레이가 활성 게임 탭에 바로 표시됩니다. 한 번만 클릭하면 해결된 보드를 화면에서 바로 확인할 수 있습니다.
* 교육용 힌트 모드: 퍼즐을 자연스럽게 푸는 방법을 배워 보세요. 자동 완성 대신 한 번에 하나의 논리적인 수를 제안받고, 화면의 빨간 하이라이트로 실수를 즉시 확인하세요.
* 스텔스 해결 속도 (스텔스 모드): 1–3초 사이의 무작위 자연 지연을 포함한 사람과 같은 클릭 동작을 모방하여, 데일리 연속 해결 기록이 봇 감지 플래그로부터 보호되도록 합니다.
* 문맥 인식 단축키: "플레이 안 함으로 표시", "풀기", "힌트 받기"와 같은 오른쪽 클릭 컨텍스트 메뉴 옵션을 게임 카드에서 바로 이용하세요.
* 로컬 Chrome 내장 AI: Google Chrome의 내장 Gemini Nano 모델을 연결하여 비용 0의 완전 로컬·개인 퍼즐 풀이 환경을 제공받으세요.
* 아름다운 분석 대시보드: 프리미엄 현대식 캘린더 대시보드로 해결 기록, 평균 시간, 연속 기록, 개인 최고 기록을 추적하세요.
* 개인적이고 안전함: 완전히 브라우저 안에서만 실행됩니다. API 키는 AES-256으로 로컬에서 암호화되며 어떤 서버와도 공유되지 않습니다. 익명 텔레메트리는 언제든지 옵트인 또는 옵트아웃할 수 있습니다.
