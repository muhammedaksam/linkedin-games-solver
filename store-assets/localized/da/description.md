# LinkedIn Games Solver

En hjælper til LinkedIn Games. Auto-løs daglige gåder (Queens, Sudoku, Pinpoint, Crossclimb) med streaks og analyser.

## Hvorfor Installere Det?
* Tab aldrig en streak: Hold dit daglige momentum kørende og sikr din streak selv på de sværeste dage eller når du har travlt.
* Mester Trivia & Ordgåder: Spil som Crossclimb og Pinpoint kræver dyb trivia viden og hurtig association. Den indbyggede AI løser dem med høj præcision.
* Hybrid Svarregister: Løs Crossclimb og Pinpoint øjeblikkeligt uden API omkostninger ved at bruge vores fjernafsvarsdatabase, ingen personlige AI nøgler kræves.
* Fuldt Bonus Games Support: Løs både standard daglige gåder og lokaliserede bonusniveauer (Queens, Sudoku osv.) problemfrit med uafhængig streak tracking og et dedikeret dashboard "Bonus" badge.
* Fuldstændig Native Integration: Solver-overlayet vises direkte på din aktive spilfane. Et klik, og du ser det løste bræt lige på skærmen.
* Uddannelsesmæssig Hint-tilstand: Lær hvordan man løser gåder naturligt. I stedet for at auto-fuldføre, få et enkelt logisk træk foreslået, og fang fejl øjeblikkeligt med røde fremhævninger på skærmen.
* Stealth Solve Speed (Stealth Mode): Efterlign menneskelige klikadfærd med tilfældige, naturlige forsinkelser (1–3 sekunder) for at beskytte din daglige løsningsstreak mod bot-detektion.
* Kontekstbevidste Genveje: Nyd højreklik kontekstmenu muligheder som "Marker som Ikke Spillet", "Løs" eller "Få Hint" direkte fra spillekort.
* Lokal Chrome Indbygget AI: Forbind Google Chromes indbyggede Gemini Nano model for en omkostningsfri, helt lokal og privat gådeløsningsoplevelse.
* Smukt Analyse Dashboard: Spor din løsningshistorik, gennemsnitlige tider, streaks og personlige rekorder med vores premium, moderne kalenderdashboard.
* Privat & Sikker: Kører helt i din browser. Dine API nøgler er krypteret lokalt ved hjælp af AES-256 og deles aldrig med nogen server. Vælg ind eller ud af anonym telemetri når som helst.
